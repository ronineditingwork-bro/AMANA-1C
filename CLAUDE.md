# AMANA-1C: заметки для Claude

Пользователь работает в 1С:Управление торговлей 11.5 (платформа 8.3.27), база «Amana», файловая (D:\Base),
опубликована на Apache сервера AMANA1 (192.168.1.10) как `/ut11`. Общение с пользователем на русском.

## Правила

* Данные 1С только читаем. Не пытайся создавать, менять или удалять объекты в 1С (POST/PATCH/DELETE),
  пока пользователь явно не попросит и это не будет реализовано отдельно.
* Прежде чем отвечать цифрами, проверь их источник: какой документ/регистр, период, фильтры. Если поле
  или объект не опубликованы в OData, скажи об этом, а не подставляй догадки.
* Пароли не выводи и не записывай никуда, кроме `.env`.

## OData 1С: соглашения

* Имена наборов: `Catalog_<Имя>`, `Document_<Имя>`, `Document_<Имя>_<ТабЧасть>`, `AccumulationRegister_<Имя>`,
  `InformationRegister_<Имя>`. Виртуальные таблицы: `AccumulationRegister_ТоварыНаСкладах/Balance()`,
  `.../Turnovers(StartPeriod=datetime'...',EndPeriod=datetime'...')`; поля результата с суффиксами
  `Balance`, `Turnover`, `Receipt`, `Expense`.
* Ссылки — поля `<Имя>_Key` (GUID); пустая ссылка `00000000-0000-0000-0000-000000000000`.
* Даты в фильтре: `Date ge datetime'2026-01-01T00:00:00'`. Проведённые: `Posted eq true`.
* Табличная часть «Товары» приходит массивом внутри документа (`Номенклатура_Key`, `Количество`, `Сумма`, `Цена`).
* Список опубликованных объектов и полей: `list_entity_sets`, `describe_entity`.

## Структура

* `onec_mcp/odata.py` — HTTP-клиент OData (только GET).
* `onec_mcp/analytics.py` — расчёты: продажи, остатки, в пути, последний поставщик, заявка, анализ заказов.
* `onec_mcp/server.py` — MCP-инструменты. Запуск: `python -m onec_mcp` (прописан в `.mcp.json`).
* `onec_mcp/check.py` — проверка подключения из консоли.
* Выгрузки CSV — в `exports/` (в git не попадает).
