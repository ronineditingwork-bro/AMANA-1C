# AMANA-1C

Подключение Claude к 1С:Управление торговлей 11 (база Amana) для анализа заказов и подготовки заявок поставщикам.

Работает через стандартный интерфейс OData 1С (`http://192.168.1.10/ut11/odata/standard.odata/`).
Коннектор **только читает** данные: в 1С ничего не создаёт и не меняет.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `check_connection` | Проверяет подключение и какие объекты опубликованы в OData |
| `sales_report` | Продажи по товарам за период (реализации минус возвраты), выгрузка в CSV |
| `customer_orders_summary` | Заказы клиентов за период: суммы, статусы, топ клиентов и товаров |
| `register_balance` | Остатки любого регистра накопления (ТоварыНаСкладах, ЗаказыПоставщикам…) |
| `reorder_suggestion` | Черновик заявок поставщикам с разбивкой по поставщикам, выгрузка в CSV |
| `list_entity_sets`, `describe_entity`, `odata_query` | Произвольные запросы для любых других вопросов |

### Как считается заявка поставщику

```
продаж в день = продано за N дней / N
нужно         = продаж в день × (срок поставки + запас дней) − (в наличии − резерв) − в пути
```

* Поставщик берётся из последнего поступления товара за год.
* «В пути» берётся из остатков регистра `ЗаказыПоставщикам`; какое поле использовано, пишется в ответе.
* Услуги и группы номенклатуры пропускаются.
* По умолчанию: 90 дней продаж, срок поставки 14 дней, запас 30 дней. Всё меняется в запросе.

Файлы CSV сохраняются в папку `exports/` и открываются в Excel двойным кликом.

## Установка (Windows, компьютер в офисной сети)

Компьютер должен видеть сервер 1С: адрес `http://192.168.1.10/ut11` открывается в браузере.

1. **Python 3.12**: скачать с https://www.python.org/downloads/. При установке отметить **«Add python.exe to PATH»**.
2. **Git**: https://git-scm.com/download/win (все настройки по умолчанию).
3. **Claude Code**: в PowerShell выполнить
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
4. Скачать проект и установить зависимости:
   ```powershell
   cd $HOME
   git clone https://github.com/ronineditingwork-bro/AMANA-1C.git
   cd AMANA-1C
   python -m pip install -r requirements.txt
   ```
5. Настройка доступа к 1С:
   ```powershell
   copy .env.example .env
   notepad .env
   ```
   Вписать пароль пользователя OData (`ONEC_PASSWORD=`) и сохранить. Файл `.env` не попадает в git.
6. Проверка:
   ```powershell
   python -m onec_mcp.check
   ```
   Должно появиться `"подключение": "ok"` и список опубликованных объектов.
7. Запуск: в папке `AMANA-1C` выполнить `claude`. При первом запуске разрешить MCP-сервер `1c`.

## Примеры запросов к Claude

* «Проверь подключение к 1С»
* «Сделай заявку поставщикам: продажи за 90 дней, срок поставки 10 дней, запас на месяц»
* «Заявка только по поставщику Grohe, склад Основной»
* «Проанализируй заказы клиентов за сентябрь: кто больше всего заказал, что в статусе к отгрузке»
* «Топ-30 товаров по продажам за квартал, выгрузи в Excel»

## Безопасность

* Для OData используется отдельный пользователь 1С (`odata.user`), только с нужными объектами.
* Пароли хранятся только в локальном `.env`.
* Коннектор выполняет только GET-запросы. Создание заказов поставщикам в 1С — отдельный следующий этап.

## Дистанционное управление (телефон / веб — в разработке)

Отдельная от Claude Code система для доступа к 1С не только с офисного компьютера, но и с
телефона или другого компьютера — без открытия портов на офисном роутере.

**Как устроено.** `local_agent/` — служба на офисном компьютере, которая сама, исходящим
соединением, раз в несколько секунд спрашивает у `cloud_api/` «есть задача?», выполняет её
через 1С (используя тот же код, что и `onec_mcp/`) и присылает результат. Телефон или веб-страница
создают задачи и читают результаты через `cloud_api/` по HTTPS с токеном.

```
Телефон / веб  →  Cloud API (облако)  ←  Local Agent (офисный ПК, сам стучится наружу)  →  1С
```

**Статус.** Первая контрольная точка — команда `GET_ORDERS` («последние N заказов клиентов»),
проверена целиком end-to-end. `CHECK_STOCK` реализована. `CHECK_RECEIPTS` (контроль поступления)
и `CREATE_SUPPLIER_ORDER` (создание заказа поставщику в 1С, требует прав на запись) — ещё
не реализованы, задачи этого типа сейчас просто отвечают, что пока не готовы.

**Запуск для проверки** — см. `cloud_api/README.md`. Хостинг для Cloud API (VPS или бесплатный
облачный сервис) ещё не выбран; пока всё проверяется локально, на `127.0.0.1`.
